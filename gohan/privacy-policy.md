# ごはん屋さんで何食べよう？ プライバシーポリシー

最終更新日: 2026年11月24日

本アプリの開発者（以下「私たち」）は、Android アプリ「ごはん屋さんで何食べよう？」（以下「本アプリ」）における利用者の情報の取り扱いについて、以下のとおり定めます。

本アプリは、予算に合わせてチェーン店のメニューの組み合わせをランダムに選ぶアプリです。アカウントの登録はなく、私たちはサーバーを持っていないため、利用者の情報を私たちが受け取ることはありません。本アプリの通信は、メニューのデータの取得と、広告（Google AdMob）のためのものだけです。

## 1. 端末に保存する情報
本アプリは、次の情報を利用者の端末の中（本アプリ専用の領域）に保存します。

- ガチャの履歴（選んだお店、予算と人数、選ばれたメニュー、日時）
- アプリの設定（選んでいるお店、予算、条件、お店の並び順、20歳以上であることの確認の有無、メニューを最後に確認した日時など）
- 取得したメニューのデータ（下の「2. メニューのデータの取得」）

これらの情報を私たちや第三者に送ることはありません。履歴は設定画面の「履歴をすべて削除」で消せます。本アプリをアンインストールすると、端末に保存したすべての情報が消えます。

## 2. メニューのデータの取得
本アプリは、お店のメニューのデータを新しくするため、起動したとき（前回の確認から24時間以上たっているとき）と、設定画面の「メニューを今すぐ更新」を押したときに、私たちが GitHub Pages（GitHub, Inc. のウェブサイトの公開サービス）に置いているファイル（https://friegen.github.io/gohan/menu/ 以下）を取得します。

このとき、利用者の情報やアプリの中の情報（履歴・設定など）は送りません。ただし、通常のウェブサイトの閲覧と同じように、通信の仕組み上、IP アドレスや端末・アプリの種類などの情報が GitHub のサーバーに届き、GitHub によって記録されることがあります。これらは GitHub のポリシーに従って取り扱われ、私たちが受け取ることはありません。詳しくは [GitHub のプライバシーに関する声明](https://docs.github.com/site-policy/privacy-policies/github-general-privacy-statement)をご覧ください。

## 3. 結果の共有
ガチャの結果の画面で「共有」を押すと、結果の画像（端末の中で作ります）と文章を、利用者が選んだアプリ（SNS など）に渡します。渡した画像と文章は、そのアプリの運営者のポリシーに従って取り扱われます。

共有の画面に SNS のアプリだけを表示するため、画像を受け取れるアプリの一覧を端末の中で調べます。この一覧を私たちや第三者に送ることはありません。また、共有の文章を受け取らないアプリでも投稿に使えるように、共有するときに文章を端末のクリップボードにコピーします。

## 4. Android の自動バックアップ
端末の設定でバックアップが有効になっている場合、本アプリの履歴と設定が利用者の Google アカウント（Google ドライブ）にバックアップされ、機種変更のときなどに復元されます。取得したメニューのデータはバックアップしません。バックアップは Google が提供する機能で、[Google のプライバシーポリシー](https://policies.google.com/privacy)に従って取り扱われます。

## 5. 広告（Google AdMob）
本アプリは、広告を表示するために Google が提供する広告配信サービス「Google AdMob」を利用しています。

AdMob は、広告の配信、広告の効果の測定、不正の防止などのために、次のような情報を収集・利用することがあります。

- 端末の広告 ID（Android の広告 ID）などの端末の識別子
- IP アドレス（おおよその地域の推定に使われることがあります）
- 端末や OS の種類、言語などの端末の情報
- 広告の表示やタップなど、広告に対する操作の情報
- アプリの動作に関する診断情報

これらの情報は Google が収集し、Google のポリシーに従って取り扱います。本アプリの履歴や設定を広告に使うことはありません。詳しくは以下をご覧ください。

- [Google のプライバシーポリシー](https://policies.google.com/privacy)
- [Google のパートナーのサイトやアプリを使用する際の Google によるデータ使用](https://policies.google.com/technologies/partner-sites)

欧州経済領域（EEA）、英国、スイスなど、法律で利用者の同意が必要な地域では、Google の User Messaging Platform を使って同意を確認し、同意の内容に従って広告を表示します。同意の内容は、本アプリの設定画面の「広告のプライバシー設定」からいつでも変更できます。

利用者は、次の方法で広告のパーソナライズを制限できます。

- 端末の設定から広告 ID を削除またはリセットする（例: 設定 ＞ セキュリティとプライバシー ＞ その他のプライバシー設定 ＞ 広告。項目の名前は端末によって異なります）
- [Google マイ アド センター](https://myadcenter.google.com/)で広告の設定を変更する

## 6. 第三者への提供
上記のメニューのデータの取得の際に GitHub に届く情報、利用者が共有を選んだときに選んだアプリに渡す画像と文章、および広告配信のための Google による情報の収集を除き、利用者の情報を第三者に提供することはありません。

## 7. 子どもの利用
本アプリは、13歳未満の子どもを対象としたものではありません。また、本アプリはアルコールを含むメニューを表示することがあります。20歳未満の方の飲酒は法律で禁止されています。
